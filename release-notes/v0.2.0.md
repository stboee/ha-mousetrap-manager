## Åte, inspeksjon og sensorkontakt

- Integrasjonssymbol basert på `mdi:rodent`, levert lokalt for lys og mørk visning med Apache 2.0-lisens og kildehenvisning.
- Oppspent felle uten mus under aktiv overvåking. Utløst felle med kontrollsymbol når bevegelse må undersøkes.
- Åtealder, åtebyttetidspunkt og konfigurerbar visning per felle. «Åte byttet» finnes sammen med kontrollhandlingene, ikke som permanent kortknapp.
- Periodisk inspeksjon med intervall per felle (0 = av), siste/neste inspeksjon, alder og binær entitet for overskredet frist.
- «Inspeksjon utført» ved periodisk ettersyn. Bekreftet fangst og falsk alarm registrerer også at felle og åte er inspisert. Inspeksjon nullstiller ikke åtealder.
- Åtebytte og inspeksjon logges, lagres på serveren og overlever restart. Åtebytte kvitterer ikke en ventende kontroll eller endrer fangsttall.
- Valgfrie HA-inspeksjonsvarsler uten mobilvarsling, med hovedbryter og separat valg for bevegelsesvarsler. Frister følges opp uten åpent dashboard.
- «Siste sensorkontakt» som entitet og lesbar alder i kortet. Bygger på faktisk `last_seen` fra Zigbee2MQTT, aldri på HA-oppdatering eller MQTT-leveringstid alene.

## Oppgradering

Oppdater integrasjonen i HACS, start HA på nytt, og endre dashboardressursen til:

`/mousetrap_manager/mousetrap-manager-card.js?v=0.2.0`

Last deretter nettleseren/appen på nytt. Feller og historikk videreføres; integrasjonen skal ikke slettes. Manuelt installerte oppsett oppdateres ved å erstatte integrasjonsmappen med innholdet fra `mousetrap-manager-v0.2.0.zip`.

Velg inspeksjonsintervall, åtevisning og inspeksjonsvarsler under **Konfigurer → Rediger eller arkiver felle**. Hovedbryteren under **Innstillinger og varsler** må være på for at varsler skal vises; bevegelsesvarsler kan være av.

For siste sensorkontakt må `last_seen` aktiveres i Zigbee2MQTT, for eksempel `advanced: {last_seen: ISO_8601}`. Uten denne verdien vises kontakttidspunkt som ukjent. Åtealder er ukjent frem til første registrerte bytte. Tidligere fangstbekreftelser/falske alarmer gir sitt faktiske tidspunkt som siste inspeksjon.

- Fysisk test i brukerens HA og på musefellen gjenstår. Se README for akseptansetesten.

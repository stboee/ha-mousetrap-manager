# Mousetrap Manager 0.5.0

Velg egen illustrasjon for **Rapp 2** og **Biltema Giljotin** i tillegg til den klassiske klappfellen. Valget lagres per felle i integrasjonen og vises på både PC og mobil.

- Nye SVG-er for aktiv overvåking, kontrollbehov, inspeksjon og utilgjengelig sensor, med tydelige statusmerker.
- Eksisterende feller beholder klassisk illustrasjon. Bytte av grafikk beholder felle-ID, fangster, åtehistorikk, inspeksjon og ventende kontroll.
- Ingen endring i vibrasjonsovervåking, kontrollhandlinger, tilsynskort, Victor-grafikk eller tellere.

Oppdater hele integrasjonen i HACS og start Home Assistant på nytt. Bruk dashboardressursen `/mousetrap_manager/mousetrap-manager-card.js?v=0.5.0` og last nettleseren/appen på nytt.

Velg **Innstillinger → Enheter og tjenester → Mousetrap Manager → Konfigurer → Rediger eller arkiver felle → ønsket felle → Felleillustrasjon**. Valget finnes også ved registrering av ny klappfelle. Det krever ikke Overstyr felles visning.

Validert med Home Assistant 2026.10.4, backendtester og nettlesertester, inkludert alle nye statusbilder og mobil-/PC-layout. Fysiske feller må funksjonsprøves hos brukeren som før.

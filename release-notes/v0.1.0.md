Første versjon av Mousetrap Manager for Home Assistant **2026.10.4**.

## Funksjoner

- Felles, varig register for vibrasjonsfeller uten manuelle hjelpere per felle.
- Aqara DJT12LM/T1 via Zigbee2MQTT: bevegelse gir kontrollbehov; bekreftet fangst gir +1.
- Kvittering etter fysisk kontroll og klargjøring, med konfigurerbar sperretid.
- Vern mot dobbeltregistrering fra samme eller flere skjermer.
- Fangstteller per felle, samlet teller og vanlig HA-langtidsstatistikk.
- Lesbar hendelseslogg og angring av siste fangst i integrasjonens administrasjon.
- Ingen mobilvarsling. Valgfrie varsler i HAs varslingspanel er avslått som standard.
- Egen variant av Rodent Trap Card 1.4, med opprinnelig funksjonalitet og kildehenvisninger bevart.

## Installasjon

1. Last ned **mousetrap-manager-v0.1.0.zip** fra denne releasen og pakk ut i en midlertidig mappe.
2. Kopier hele mappen **mousetrap_manager** til **<HA-konfigurasjon>/custom_components/**.
3. Start Home Assistant på nytt og legg til integrasjonen Mousetrap Manager.
4. Registrer sensoren og eksakt MQTT-topic under Konfigurer. Første kjente sensor bruker `zigbee2mqtt/Vibrasjon`.
5. Legg til `/mousetrap_manager/mousetrap-manager-card.js?v=0.1.0` som JavaScript-modul under dashboardressurser, og legg til kortet.

Installasjonsarkivet inneholder integrasjonen, kortfilen, lisens, opphav og installasjonsbeskrivelse. Full kildekode finnes i de automatisk genererte kildearkivene. Filen med endelsen `.sha256` inneholder kontrollsummen til installasjonsarkivet.

## Verifisering og grenser

30 backendtester og 582 frontendkontroller er bestått. Backend er testet mot selve Home Assistant 2026.10.4-pakken. GitHub kjører testene på release-commit før publisering.

Fysisk testing med den faktiske Aqara-sensoren gjenstår. Varsler kan slås helt av. En angring korrigerer telleren når handlingen utføres; eldre HA-statistikkperioder omskrives ikke. Privat HACS-installasjon er ikke verifisert. Se README for full beskrivelse og fysisk akseptansetest.

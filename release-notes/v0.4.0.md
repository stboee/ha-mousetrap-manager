Kompakt tilsynsvisning for startsider med betingede alarmkort.

- Samme korttype får `mode: attention`, med bare navn og årsaker for berørte feller. Fullvisning er fortsatt standard.
- Én automatisk opprettet binærsensor samler tilsynsbehov. Integrasjonen beregner årsaker, prioritering og ferdige rader. Nye aktive feller inkluderes og arkiverte utelates.
- Én felle telles én gang selv med flere årsaker. Ingen ny fangsttotal eller langtidsstatistikk.
- Nytt oppsett: Konfigurer → Tilsynsvisning på startsiden. Fangst, bevegelse, inspeksjon og kildeproblemer er med som standard. Batteri og kontakt kan velges separat. Valgene er uavhengige av varslinger.
- Adressestien til fullvisningen velges i integrasjonen. Den er tom ved oppgradering fordi dashboardadressen ikke er kjent.
- Korteditoren velger full/tilsyn og setter HAs betingede synlighet automatisk. Ukjent/utilgjengelig tilsynsstatus vises som feil; gamle fangstopplysninger brukes ikke som normalstatus.
- Synlig versjonsnummer i editoren. Native HA-valg for layout og synlighet gir ikke advarsel om gamle kortvalg. Fullvisning gjenopprettes etter et midlertidig utilgjengelig kortoppsett.

Oppgrader hele integrasjonen via HACS og start HA på nytt. Endre ressursen til `/mousetrap_manager/mousetrap-manager-card.js?v=0.4.0`, og last nettleseren/appen på nytt. Historikk, eksisterende feller, tellere, vedlikehold og Victor-gjenoppretting beholdes.

Legg deretter til et kort på startsiden og velg Tilsyn i editoren. Kontroller måladressen under integrasjonens tilsynsoppsett. Fullvisningen på Musefeller-fanen bruker fortsatt `type: custom:mousetrap-manager-card`.

Programvaren er kontrollert mot Home Assistant 2026.10.4 og i nettleser. Endelig kontroll på brukerens dashboard og fysiske feller gjenstår.

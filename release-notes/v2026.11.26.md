# Mousetrap Manager v2026.11.26 – Sesongpause, testfeller og statistikk

- **Sesongpause** erstatter Arkiver. Oppsett og historikk beholdes. Ved klargjøring etter pausen blir inspeksjon registrert, med eget valg for åtebytte.
- **Testfeller** merkes i fullvisningen og har en egen testlogg. Nullstilling rydder testhistorikken og beholder oppsett og eventuell tidligere driftshistorikk.
- **Fjern felle, behold historikk** frigjør sensoren og beholder fangstene. **Slett felle og historikk** trekker fellens driftsfangster fra klappfelletelleren. Eventuell tidligere HA Recorder-statistikk bevares.
- **Klappfeller i bruk** og **Victor-feller i bruk** er separate målesensorer for HA-statistikk. Feller på sesongpause og testfeller er utelatt.
- Fire valg under **Konfigurer** samler Feller, Varsler i Home Assistant, Kort og tilsyn og Driftsinnstillinger. Varsling kan overstyres per felle og varslingstype.

Oppdater hele integrasjonen i HACS og start Home Assistant på nytt. Bruk kortressursen `/mousetrap_manager/mousetrap-manager-card.js?v=2026.11.26` og last nettleseren eller appen på nytt. Eksisterende feller, fangster, vedlikehold, ventende kontroller og statussensorenes ID-er videreføres.

Denne utgivelsen starter datobasert versjonering i formatet `ÅÅÅÅ.MM.DD`.

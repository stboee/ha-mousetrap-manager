Vi utvikler en egen variant med separat custom-element-navn. Fra 0.3.0 eier integrasjonen status og oppsett; runtimekortet er skrevet om for denne presentasjonsmodellen. Snap-illustrasjonen er videreført og avledet fra originalen. Victor M1-grafikken er egen SVG-grafikk etter brukerens produktreferanse, godkjent utkast 2 (GPL-3.0-or-later). HA-temavariabler for tekst, kort, bakgrunn og skillelinjer brukes. Endringer fra originalprosjektet hentes ikke automatisk inn. En eventuell oppdatering vurderes med egen diff, tester og pull request.

Originalens runtimefil beholdes i `dist/rodent-trap-card.js`. README er kopiert til `docs/upstream/README.md` som referanse; bilder/lenker som er relative til originalprosjektet må ses der. Testene av vår tidligere frontendmodell finnes i tag v0.2.1; nye frontend- og backendtester dekker presentasjonsmodellen fra 0.3.0. Testene for originalprosjektets releaseflyt er arkivert, ikke brukt som validering av vår releaseflyt.
